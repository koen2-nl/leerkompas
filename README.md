# LeerKompas

**Leren op jouw manier.** Een moderne, speelse en responsive leeromgeving voor vakken, flashcards, quizzen en studieplanning.

## Snel starten

```bash
npm install
npm run dev
```

Maak een productiebuild met `npm run build`.

## In deze eerste demo

- Dashboard met widgets en studie-overzicht
- Vakken beheren en doorzoeken
- Flashcards om begrippen te oefenen
- Quiz Rush-vraag met feedback
- Game-overzicht, voortgang en planning
- Donker thema en vier accentkleuren
- Responsive navigatie voor mobiel en desktop

## Belangrijk

Dit is een front-end demonstratie met tijdelijke voorbeeldgegevens. Er zijn nog geen accounts, database, cloudopslag of echte synchronisatie. De demo reset bij vernieuwen. Zie [docs/PROJECT.md](docs/PROJECT.md) voor de architectuur, beperkingen en vervolgstappen.

## Technologie

React, Vite en Lucide React. Geen API-sleutels of servergeheimen nodig.
