# Leervo

**Leren op jouw manier.**

Leervo is een rustige, persoonlijke en responsive leeromgeving voor vakken, lessen, flashcards, quizzen en studieplanning.

Website: [https://leervo.nl](https://leervo.nl)

## Snel starten

```bash
npm install
npm run dev
```

Maak een productiebuild met:

```bash
npm run build
```

## Technologie

- React en Vite
- Supabase voor accounts en synchronisatie
- Lucide voor interface-iconen

## Projectafspraken

- Bestaande accounts, lessen en voortgang blijven behouden bij visuele updates.
- Iedere release werkt zowel `src/changelog.js` als `docs/CHANGELOG.md` bij.
- Productiewijzigingen worden pas live gezet na controle van de preview.
